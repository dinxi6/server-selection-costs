## 配置底线：2核2G，带宽别低于3M

个人网站的流量普遍不大。按日 IP 算，1000 以内的站点用最低配置完全撑得住；日 IP 上万，再考虑 2核4G 或更高。主流云服务器大多支持后续升配，先用小配置跑起来、流量涨了再升级，比一步到位省钱。

配置里比 CPU 和内存更常被忽视的是带宽。1Mbps 带宽的理论下载速度只有 128KB/s，页面里多放几张图，访客就要多等好几秒。国内站点建议至少 3Mbps 起步；预算实在紧，也要看清套餐带的带宽大小，别只盯着核数和内存。

## 境内还是境外：备案这道坎

境内机房的优势是访客访问稳定、搜索引擎收录友好，代价是必须备案：提交身份证、核验照片和网站资料，流程一般 2-4 周。不备案的境内站点，接入 CDN 会受限，百度这类搜索引擎也基本不收录，流量很难起来。

境外机房（香港、日本、美国等）免备案，买完当天就能上线，对网站内容的限制也更少。只是练手、做临时项目、或者站点不依赖国内搜索流量，境外方案确实省事；想认真做、要搜索流量，备案这 2-4 周值得等，一次备案长期受益。

## 常见问题

**个人建站服务器一年要花多少钱？**
几十元到两百元就能解决。国内主流厂商入门档首年价在 35-99 元之间；按两三年摊算，选续费同价的套餐，年成本可以稳定控制在百元以内。

**不备案能建站吗？**
能。选境外机房（香港、日本、美国等）购买当天就能上线，代价是百度等搜索引擎收录差、接入国内 CDN 受限，适合练手和不依赖搜索流量的站点。

**1M 带宽够用吗？**
纯文字站勉强能跑，但 1Mbps 的理论下载速度只有 128KB/s，图文稍多打开就会明显变慢，建议至少 3M 起步。

**配置买小了怎么办？**
多数云服务器支持套餐升级，数据不用重装。思路是先按日 IP 低于 1000 的需求买最低配置，流量上来再升配，不为用不满的资源付费。
